# Mode: decide (advisory)

Role: `research`. Subject: a choice between named options.

Brief: decision, options described neutrally, criteria and weights, constraints, context. Do not reveal a favorite.

Compare each option against the criteria, failure modes, reversal costs, and conditions under which it would be right. Suggest at most one missing option, with justification.

Response format (max 250 words):

1. First line: PICK: <option> | CONFIDENCE: low/med/high
2. Ranking with one-line reasons
3. Deciding factor
4. What would change your mind

Cross-examine only if core picks differ. Report a combined recommendation as unanimous, majority, or split, with the strongest argument for each surviving option. The user decides; act only when the task already authorizes implementation.
